# Fuel — calorie & macro tracker

A personal, $0-cost Android calorie tracker (Expo + Supabase) with a premium, MacroFactor-style experience:
fast food logging (search, barcode, quick add), macros, smart trend weight, adaptive calorie budget,
water, exercise, and weekly check-ins.

See [docs/PLAN.md](docs/PLAN.md) for the full feature list, screen layout, data model and build phases.
